# Recovered MoonRock/QBasic code dump research

The detailed artifact inventory and revival analysis lives in the organized working tree:

[`moonrock-revival/docs/recovered-code-research.md`](../moonrock-revival/docs/recovered-code-research.md)

Key findings:

- The 2025 code dump contains no recovered `.moo` MoonRock source.
- Eastman survives as compiled DOS `.COM` components plus QBasic map-editor, map, RPG, image, and sprite assets.
- `moonrock-revival/projects/qbasic-cube/CUBE.BAS` is a complete rotating-cube QBasic demo with homemade perspective projection and axis-rotation math.
- Later C++/Allegro projects show the subsequent development era: Asteroids, Breakout, Casino, Pong, Real Sparkler, Space Invaders, and a 3D starfield.
- The recommended first revival target is the cube, followed by DOSBox-X execution and observation of Eastman’s `.COM` scenes.
