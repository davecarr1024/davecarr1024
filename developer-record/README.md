# Developer Record

This directory holds the durable cross-project record: philosophy, portfolio inventory, planning standards, and lessons that should survive individual repositories.

## Files

- `project-philosophy.md`: converted and consolidated from the old root `projects.html` design-philosophy page.
- `project-inventory.md`: dated 2026-07-10 portfolio snapshot, converted and
  consolidated from the old root `PROJECT_SUMMARY.md` plus the project matrix
  from `projects.html`; use `../projects.md` for the live project index.
- `agent-enabled-development-process.md`: the working process from project
  thesis and naming through bite-size implementation, verification, phase
  review, and delivery.
- `open-questions-and-next-steps.md`: historical 2026-07-10 planning snapshot;
  its questions preserve the reasoning that led to later promotions, but its
  recommended next work is not current guidance.

## Purpose

Use the philosophy and process here when deciding what to build next, writing
new project agent files, or checking whether an idea fits the recurring shape
of the work. Use `../projects.md` and the project repositories for current
status.

Implementation-specific docs belong in their project repositories. Early ideas and cross-project lessons belong here.
