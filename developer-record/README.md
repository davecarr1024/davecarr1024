# Developer Record

This directory holds the durable cross-project record: philosophy, portfolio inventory, planning standards, and lessons that should survive individual repositories.

## Files

- `project-philosophy.md`: converted and consolidated from the old root `projects.html` design-philosophy page.
- `project-inventory.md`: converted and consolidated from the old root `PROJECT_SUMMARY.md` plus the project matrix from `projects.html`.

## Purpose

Use this directory when deciding what to build next, writing new project agent files, or checking whether a project idea fits the recurring shape of the work.

Implementation-specific docs belong in their project repositories. Early ideas and cross-project lessons belong here.
