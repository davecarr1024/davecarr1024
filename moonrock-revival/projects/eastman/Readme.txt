Introduction:
This is my map making suite of software (snicker), it will allow you to make textures, put
those textures on a map, and play that map. If you didn't get it when you downloaded this,
you need qb45.zip, available at http://www.geocities.com/foozballchamp/projects.html and 
various other places. Files.zip contains everything except that.


Installation:
1. Unzip qb45.zip to the directory of your choice.
2. Unzip files.zip to that same directory.
3. Open a DOS console and execute "qb /run [filename]" (without quotes) where [filename] is
   editor, map or rpg.
4. Send comments/questions/jokes like this:
   if (you.stink()) {
   	take.shower();
   }
   har har, to foozballchamp@yahoo.com


What do these do??
editor makes textures, instructions included 
	for physical value: 0 = walkable, 1 = solid, 2 = town
map makes maps, arrows move, enter selects/places piece 
	g = grass, m = mountain, w = water, t = town, spacebar repeats last stamp
	save to main.map (map outside) or town.map (map in town) to play in rpg
rpg is map user, arrows move
